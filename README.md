# Digital-currency
1. Project Title / Headline
Cryptocurrency Market Analysis Dashboard

2. Short Description
This project is a Power BI dashboard that analyzes the performance of different cryptocurrencies such as Bitcoin, Ethereum, Dogecoin, XRP, and Stellar. It provides insights into market trends, market capitalization, trading volume, opening price, high price, and low price over different years.

3. Purpose
The main purpose of this project is to:
Track cryptocurrency market performance
Compare different digital currencies
Analyze yearly market trends
Visualize market capitalization and trading volume
Help users make data-driven investment decisions through interactive dashboards

4. Tech Stack
Power BI – Data visualization and dashboard creation
Microsoft Excel / CSV – Data storage and preprocessing
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – Calculations and measures
